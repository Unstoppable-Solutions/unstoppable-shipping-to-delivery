# Changelog

All notable user-facing changes are documented here. For WordPress.org users,
the same changelog lives in `readme.txt` and renders on the plugin's directory
page. This file follows the format described at https://keepachangelog.com.

## [1.2.3]

- Tested and confirmed compatible with WordPress 7.1.3.

## [1.2.2]

- Tested with WordPress 7.0.

## [1.2.1]

- Fixed readme tags (limit 5) and short description length.

## [1.2.0]

- Added link to the Pro version for users needing custom text options.
- Minor code improvements.

## [1.1.5]

- Improved search tags for better plugin discovery.

## [1.1.4]

- Added JavaScript fallback for dynamic content.
- Catches remaining "shipping" text, including AJAX-loaded content.

## [1.1.3]

- Added filters for "no shipping available" messages.
- Added filters for shipping destination and estimate text.

## [1.1.2]

- Expanded text replacement to cover more WooCommerce areas.
- Added support for the WooCommerce Blocks text domain.
- Added uppercase SHIPPING replacement.

## [1.1.1]

- Added HPOS (High-Performance Order Storage) compatibility declaration.

## [1.1.0]

- Simplified plugin for better compatibility with all WooCommerce setups.
- Streamlined code for improved performance.

## [1.0.0]

- Initial release.
