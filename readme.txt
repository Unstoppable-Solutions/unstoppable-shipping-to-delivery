Replace "Shipping" with "Delivery" throughout WooCommerce. Perfect for restaurants and local delivery services.

== Description ==

**Unstoppable Shipping to Delivery for WooCommerce** automatically replaces all instances of "Shipping" with "Delivery" throughout your WooCommerce store.

**Who is this for?**

* 🍕 Restaurants offering delivery
* 🚗 Local delivery services
* 🌸 Florists and gift shops with same-day delivery
* 🍔 Food trucks and catering businesses
* 🛒 Grocery and meal prep delivery
* 📦 Any local business where "Delivery" makes more sense than "Shipping"

If your customers are getting their orders delivered locally (not shipped via UPS/FedEx), this plugin makes your checkout feel right.

= Features =

* **Zero Configuration** – Just activate and it works
* **Complete Coverage** – Works on cart, checkout, emails, and everywhere else
* **Dynamic Content** – Handles AJAX-loaded content (no more missed text)
* **Lightweight** – Simple, clean code with minimal overhead
* **HPOS Compatible** – Works with WooCommerce High-Performance Order Storage

== Installation ==

1. Upload the `unstoppable-shipping-to-delivery` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. That's it! No configuration needed

== Frequently Asked Questions ==

= Does this plugin require any configuration? =

No! Simply activate the plugin and all instances of "Shipping" will automatically be replaced with "Delivery" on your store.

= Where does it replace the text? =

Everywhere! Cart, checkout, order emails, order confirmation, my account pages - anywhere WooCommerce displays "Shipping".

= Will this slow down my site? =

No. The plugin is extremely lightweight and uses efficient string matching.

= Does it work with WooCommerce Blocks? =

Yes! The plugin includes a JavaScript fallback that catches dynamically loaded content.

= Can I change "Shipping" to something other than "Delivery"? =

This free version only replaces with "Delivery". For custom text options (Pickup, Billing, or any word), check out [Shipping Text Manager Pro](https://unstoppablesolutions.app/plugins/unstoppable-shipping-text-manager).
